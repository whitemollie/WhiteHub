# What's new

## 0.1.9 — 2026-11-25

- Only tested devices are queried automatically; other WLmouse models need a product ID entered by hand
- Events pushed by a device are rate-limited
- The installer contains Microsoft's WebView2 bootstrapper instead of downloading it

## 0.1.8 — 2026-11-25

- Security hardening: stricter window policy, absolute paths, cleaned USB device names
- Diagnostic reports no longer contain the user's profile folder
- GPL-3.0 licence, credits, documentation and automatic tests

## 0.1.7 — 2026-11-25

- Bolder digits (Segoe UI Black); digits, icons and bolt share one centre line

## 0.1.6 — 2026-11-25

- Readings show where they come from and how old they are

## 0.1.5 — 2026-11-25

- The window opens and closes smoothly, without a white flash
- One window size on every page

## 0.1.4 — 2026-11-24

- Charging bolt aligned with the digits

## 0.1.3 — 2026-11-24

- Sharper charging bolt

## 0.1.2 — 2026-11-24

- Filled charging bolt

## 0.1.1 — 2026-11-24

- Author on the About page
